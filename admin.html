Abrir os dados

Digite a senha dos professores. Ela é usada para abrir e para trancar o arquivo de notas.

Adicionar PDFs

Pode soltar vários de uma vez. Listas repetidas são ignoradas e listas da mesma turma e área (como inglês e espanhol) são somadas.

Solte os PDFs aqui ou clique para escolher

    Notas diferentes para o mesmo aluno

    O mesmo aluno apareceu com outra nota na mesma turma, área e simulado. Escolha qual vale.

    O que está no banco

    Cada número é a quantidade de alunos daquela turma na área. Clique para ver a lista. Turmas com números diferentes entre áreas do mesmo dia podem estar com um PDF faltando.

    Nomes das turmas

    É o nome que os professores veem no lugar do código. Turma nova ganha um nome sozinha quando o curso é conhecido; confira e corrija aqui se precisar.

    Publicar para os professores

    Nada vai para o site até você baixar o arquivo e enviá-lo ao GitHub.

    1. Abra o repositório do sistema no GitHub.
    2. Clique em Add file e depois em Upload files.
    3. Arraste o dados.enc que acabou de baixar. Ele substitui o antigo.
    4. Clique em Commit changes. Em cerca de um minuto os professores já veem as novas notas.
