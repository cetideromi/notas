Configuração do site

Feita uma vez só, por quem cuida do site. Depois a coordenação usa apenas a senha dela. Refazer só se for trocar o código do GitHub (por exemplo, quando ele vencer).

1. Senha dos professores

É a senha que os professores usam para ver as notas. Se o site já tem notas, digite a senha atual delas.

2. Senha da coordenação

Uma senha diferente da dos professores. É com ela que a coordenação entra nesta página e publica as notas.

3. Código de acesso do GitHub

Ele deixa esta página salvar as notas no site sozinha. Para criar:

  1. Entre no GitHub com a conta do site e abra github.com/settings/personal-access-tokens/new.
  2. Em Token name, escreva: site das notas.
  3. Em Expiration, escolha o prazo mais longo que aparecer.
  4. Em Repository access, escolha Only select repositories e marque o repositório do site (notas).
  5. Em Permissions, abra Repository permissions e mude Contents para Read and write.
  6. Clique em Generate token, copie o código (começa com github_pat_) e cole abaixo.
